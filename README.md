 * Цель работы: Изучение символьных и строковых переменных и способов их обработки на языке C/C++.
 * Общая постановка задачи: Задается строка, состоящая из символов и слов, разделенных пробелами и оканчивающаяся точкой (текст содержит не более 255 символов), после чего выполняется ввод и обработка строки согласно выданному варианту.
 * Задание по варианту № 1: Проверить, является ли введенная строка палиндромом (выражением, которое одинаково читается слева направо и справа налево).
 * Содержание отчета по лабораторной работе:
   * Постановка задачи для конкретного варианта.
   * Исходные данные.
   * Текст (листинг) программы.
   * Результаты выполнения программы.
